# Farm Note

Farm Note is a small note-taking app and a project for learning Rust. I’m building it to bring together ideas I like from other note apps with the cozy, farm-life feel of *Fields of Mistria* and *Stardew Valley*, plus an ASCII-inspired look.


## Run

With Rust installed, start the app with:

```sh
cargo run
```

## Status

This project is a work in progress. The current app is a simple desktop UI built with Rust and `egui`/`eframe`; note-taking features and the visual style will grow as I learn.
